Privacy Policy.

Last updated: June 5, 2026

Focus Launcher is a minimalist Android launcher designed to help users reduce distraction and manage attention. The app is built to keep focus data on the user's device.

Data We Access

Focus Launcher may access the following device data when the user enables related features:

  • Installed launchable apps, so the launcher can show app lists, favorites, hidden apps, app disguises, focus profiles, quotas, and essential notification bypasses.
  • Usage access data, only to calculate daily app quota usage for apps selected by the user.
  • Notification listener data, only to batch non-essential notifications and allow essential apps to bypass batching.
  • Notification permission, only to show Focus notification summaries on Android 13 and newer.
  • Wi-Fi network SSID, only when the user configures Wi-Fi based contextual focus profile switching.
  • Local settings and activity counters, including favorites, hidden apps, app disguises, focus profiles, quotas, notification batching counts, launch counts, deflection counts, and intent logs.

How Data Is Used

Focus Launcher uses accessed data only to provide user-facing launcher and focus features:

  • Display and launch apps.
  • Hide or disguise selected apps.
  • Apply app time quotas.
  • Switch contextual profiles.
  • Batch non-essential notifications.
  • Show notification batch summaries.
  • Show local focus statistics.

Data Sharing

Focus Launcher does not sell, share, upload, or transmit personal data. The app does not request internet access and does not include ads, analytics, cloud sync, or third-party tracking SDKs.

Data Storage and Retention

Focus Launcher stores settings and focus data locally on the device using Android DataStore. Data remains on the device until the user changes the related settings, removes app selections, clears data through Android system settings, or uninstalls the app.

User Control

Users can disable usage access, notification listener access, notification permission, and profile-related configuration through Android system settings or Focus Launcher settings. Disabling those permissions may disable the related focus features.

Contact

For privacy questions, contact the developer listed on the Google Play store listing for Focus Launcher.
