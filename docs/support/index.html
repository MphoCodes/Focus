Focus Launcher

Support

Focus Launcher is a minimalist Android launcher for reducing distraction. This page explains common setup points and where to find privacy information.

Permissions

Focus uses optional Android permissions only when you enable related features:

  • Usage access is used for daily app quotas.
  • Notification listener access is used for notification batching and essential app bypasses.
  • Notification permission is used to show notification summaries on Android 13 and newer.
  • Wi-Fi network information is used only for optional context profile switching.

Troubleshooting

  • If Focus is not your home screen, set it as the default launcher in Android settings.
  • If quotas are not updating, confirm usage access is enabled for Focus Launcher.
  • If notification batching is not active, confirm notification listener access is enabled.
  • If a feature feels too strict, disable the related Focus setting or revoke the permission in Android settings.

Privacy

Focus stores settings and focus activity locally on your device. It does not include ads, analytics, cloud sync, or third-party tracking SDKs.
