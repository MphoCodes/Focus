# Public preview preparation

1. Verify origin, existing tests, manifest permissions and release signing configuration.
2. Split launcher presentation into routing, screens, shared components and pure helpers, preserving behavior.
3. Document the implemented feature boundaries, architecture, build and debug preview installation.
4. Add the MIT license and tighten CI validation and artifact checks.
5. Run unit tests, Android lint and debug packaging; verify the APK signature and inspect tracked history for credential risks.

Release publishing and repository visibility are handled separately by the repository owner.
